# Spotify Web para Android

## Opción A: sin instalar nada (GitHub)
1. Creá una cuenta gratis en github.com y un repositorio nuevo.
2. Subí TODO el contenido de esta carpeta (incluida la carpeta oculta .github).
3. Entrá a la pestaña "Actions" -> "Build APK" -> esperá ~3 min.
4. Abrí la ejecución terminada y bajá "SpotifyWeb-apk" (zip con app-debug.apk).
5. Pasalo al celu, abrilo y permití "instalar apps desconocidas".

## Opción B: Android Studio
Abrí esta carpeta con Android Studio -> Build -> Build APK(s).
El archivo queda en app/build/outputs/apk/debug/app-debug.apk
